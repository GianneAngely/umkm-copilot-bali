# Lisensi font

Semua font di folder ini adalah subset Latin dalam format WOFF2, diambil dari Google Fonts, dan disimpan di repo supaya build dan tampilan tidak bergantung pada server Google.

| Berkas | Font | Pemegang hak cipta | Lisensi |
|---|---|---|---|
| `PlusJakartaSans-latin.woff2` | Plus Jakarta Sans (variabel 200–800) | The Plus Jakarta Sans Project Authors (Tokotype) | SIL Open Font License 1.1 |
| `Newsreader-latin.woff2` | Newsreader (variabel 200–800) | The Newsreader Project Authors (Production Type) | SIL Open Font License 1.1 |
| `IBMPlexMono-Regular-latin.woff2`, `IBMPlexMono-SemiBold-latin.woff2` | IBM Plex Mono 400 dan 600 | IBM Corp. | SIL Open Font License 1.1 |
| `Caveat-latin.woff2` | Caveat (variabel 400–700) | The Caveat Project Authors (Impallari Type) | SIL Open Font License 1.1 |

Teks lengkap lisensi: https://openfontlicense.org/open-font-license-official-text/
